# 社团报名系统 · 操作指南

> 本系统为纯前端 HTML 原型,无需后端。但因集成了 Dify 聊天气泡助手,**必须通过 HTTP 协议访问**,不能直接双击打开(`file://` 会导致 Dify 拒绝连接)。

---

## 一、本地预览(开发者自己看)

### 方式 1️⃣:双击启动脚本(最简单,需 Python)

1. 双击目录内的 `启动.bat`
2. 浏览器会自动打开,无需手动操作
3. 用完关闭弹出的黑色命令窗口即可停止服务器

> 前提:电脑已安装 Python 3.x 并配置了环境变量(终端输入 `python --version` 有响应)。

### 方式 2️⃣:手动命令(需 Python)

打开 PowerShell 或 CMD,执行:

```powershell
cd "你的路径\demo"
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问:http://127.0.0.1:8000/原型.html

停止:在命令行窗口按 `Ctrl + C`

### 方式 3️⃣:Node.js(无 Python 但有 Node)

```powershell
cd "你的路径\demo"
npx http-server -p 8000 -a 127.0.0.1
```

浏览器访问:http://127.0.0.1:8000/原型.html

### 方式 4️⃣:VS Code Live Server 扩展(推荐开发者用)

1. VS Code 安装扩展 **Live Server**(作者:Ritwick Dey)
2. 右键 `原型.html` → **Open with Live Server**
3. 自动通过 `http://127.0.0.1:5500/原型.html` 打开,支持热重载

## 二、线上部署(给别人访问)

上传到 GitHub 后,推荐用 **GitHub Pages** 免费部署,这样任何访客都无需本地环境:

### 步骤:
1. 把整个 `demo` 目录推送到 GitHub 仓库
2. 仓库 → **Settings** → **Pages**
3. **Source** 选 `Deploy from a branch`
4. **Branch** 选 `main` / `root`(或 `docs` 文件夹,看你把文件放哪)
5. 保存,等待 1-2 分钟
6. 访问地址形如:`https://你的用户名.github.io/仓库名/原型.html`

### 注意事项:
- 文件名 `原型.html` 含中文,部分场景可能有问题。如需更稳,可重命名为 `index.html`,这样直接访问仓库名即可
- 部署后 Dify 气泡直接可用,无需任何额外配置

## 三、Dify 聊天气泡说明

本系统集成了 **Dify 社团问答助手**(右下角蓝色气泡按钮),用于帮助学生快速了解适合自己的社团。

### 显示规则
- **身份选择页面、登录页面**:气泡**不显示**
- **管理员/教师页面**:气泡**不显示**(仅限学生使用)
- **学生主页及子页面**(浏览社团、我的报名、个人中心):气泡**显示**
- **退出登录后**:气泡自动隐藏

### 位置说明
气泡按钮固定在**手机屏幕内部右下角**,而非浏览器视口边缘。点击后聊天窗口从按钮上方弹出,完全位于手机外框内。

如需更换或移除 Dify 助手,编辑 `原型.html` 末尾的 Dify 配置代码块即可。

### ⚠️ Token 配置说明（首次部署必读）

`原型.html` 中默认使用占位符 `YOUR_DIFY_TOKEN`,**首次使用前必须替换为你自己的 Token**,否则气泡无法正常工作。

#### 替换步骤:
1. 登录 [Dify 控制台](https://udify.app) → 进入你的社团推荐应用
2. 顶部菜单 → 『嵌入分享』→ 选择『聊天气泡嵌入』
3. 复制嵌入代码中的 `token` 值(形如 `JgBQ5BQ9Ii9H3gmc`)
4. 打开 `原型.html`,搜索 `YOUR_DIFY_TOKEN`,全部替换为你复制的 Token(共两处:一处在 config 对象里,一处在 script 标签的 id 属性上)

#### 安全建议:
- 在 Dify 控制台 → 应用 → 设置 → 『嵌入分享安全设置』中开启**域名白名单**,只允许你的本地地址(`http://127.0.0.1:*`、`http://localhost:*`)和你的 GitHub Pages 域名(`https://你的用户名.github.io/*`)访问
- 演示用 Token 不保证长期可用,建议用自己的 Dify 账号创建应用并替换

#### 不想用 AI 功能怎么办?
直接删除 `原型.html` 里从 `<!-- ========== Dify 社团问答助手 ========== -->` 开始到最后一个 `</style>` 之间的所有代码即可,不影响报名系统原型使用。

## 四、常见问题

### ❓ Dify 聊天气泡提示"拒绝连接"

原因和解决:
| 原因 | 解决 |
|------|------|
| 用 `file://` 双击打开 | 改用上述 HTTP 方式访问 |
| Dify 应用未发布 | 回 Dify 后台点"发布"按钮 |
| Dify 嵌入里设了域名白名单 | 把访问域名加进去,或关闭白名单 |
| 网络无法访问 udify.app | 国内网络有时不稳,需代理 |

### ❓ 双击 `启动.bat` 闪退

说明没装 Python 或未配置环境变量。解决方案:
- 安装 Python:https://www.python.org/downloads/(安装时勾选 "Add Python to PATH")
- 或改用方式 3(Node.js)/方式 4(VS Code)

### ❓ 端口 8000 被占用

换一个端口,例如 `python -m http.server 8080`,然后访问 `http://127.0.0.1:8080/原型.html`。
